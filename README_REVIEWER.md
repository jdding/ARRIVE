# Reviewer entry

Start with [README.md](README.md) and [ARTIFACT_QUICKSTART.md](ARTIFACT_QUICKSTART.md).
The protocol, feature schema and export contract are documented in `docs/`.
The smoke and contract tests require no music data; training on prepared exports
requires separately supplied inputs. [coverage.md](docs/coverage.md) lists the
source coverage and unverified real-data execution. The stage-by-stage
[reproduction guide](reproduction/README.md) covers data preparation, SASRec and
SSD4Rec training, native export, controls and three-seed analysis. It also lists
the required data/assets and the incomplete historical baseline-search record.
